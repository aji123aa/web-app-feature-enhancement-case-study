# Mention Input Demo

## Overview

This feature demonstrates a generic mention input workflow for a content-based web application. It allows users to type `@` and select a person from a suggestion list.

## Problem

In collaborative content platforms, users may need to mention other users inside posts, comments, or article content. A normal text input does not provide a structured way to search and insert mentions.

## Solution

The demo provides a simple mention input where users can:

- Type `@` to trigger suggestions
- Search users by name
- Select a user from the suggestion list
- Insert the selected mention into the content
- Track selected mentions separately

## Key Features

- `@` trigger detection
- User suggestion dropdown
- Search/filter logic
- Mention insertion into textarea
- Selected mention tracking
- Preview display
- Mock user data

## Tech Concepts Used

- React functional components
- React state management
- `useMemo`
- Input parsing
- Search/filter logic
- Conditional rendering
- Basic mention tagging workflow
