# Profile Photo Cropper Demo

## Overview

This feature demonstrates a reusable profile photo cropping component for a web application. It allows users to upload a profile image, reposition it, zoom in/out, and save the final cropped image as a square profile photo.

## Problem

Users may upload images with different sizes, aspect ratios, and framing. Without a cropping workflow, profile photos can appear stretched, misaligned, or poorly fitted.

## Solution

The demo provides a profile photo adjustment modal where users can:

- Preview the selected image
- Move the image inside the crop frame
- Zoom in or out
- Crop the image in a square format
- Generate an 800 × 800 profile photo output

## Key Features

- Image crop and zoom support
- Circular profile crop preview
- Canvas-based image processing
- Square output generation
- Error handling for invalid crop operations
- Generic reusable component structure

## Tech Concepts Used

- React functional components
- React state management
- React hooks
- `react-easy-crop`
- HTML Canvas API
- File and Blob handling
- Client-side image processing
