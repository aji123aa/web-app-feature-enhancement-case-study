# KPI Dashboard Cards Demo

## Overview

This feature demonstrates KPI cards for a content dashboard. The purpose of the cards is to provide users with a quick summary of content-related statistics.

## Problem

When a content module contains multiple items, users need a simple way to understand overall activity, publishing status, and engagement without manually checking each item.

## Solution

The demo calculates and displays key metrics from sample content data.

Users can view:

- Total posts
- Published posts
- Draft posts
- Scheduled posts
- Total views
- Total comments

## Key Features

- KPI calculation from sample data
- Dashboard card layout
- Status-based content grouping
- Simple content table
- Responsive card grid
- Clean visual summary

## Tech Concepts Used

- React functional components
- Array filtering and reduction
- Component reuse
- Dashboard UI structure
- Data presentation
- Conditional/statistical calculation
