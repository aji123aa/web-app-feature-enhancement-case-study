# Exit Confirmation Card Demo

## Overview

This feature demonstrates an exit confirmation card for a content editing workflow. It helps prevent users from accidentally leaving the page when unsaved changes are present.

## Problem

When users are writing or editing content, they may accidentally click exit or navigate away before saving. This can result in loss of work and a poor user experience.

## Solution

The demo checks whether unsaved changes exist before allowing the user to exit. If changes are detected, a confirmation card is displayed with clear actions.

Users can:

- Continue editing
- Discard changes and exit
- Save changes and exit

## Key Features

- Unsaved change detection
- Exit confirmation card
- Continue editing action
- Discard changes action
- Save and exit action
- Simple status message handling
- Reusable UI logic
