# Content Scheduling Demo

## Overview

This feature demonstrates a generic content scheduling workflow for a web application. It allows content to be saved as a draft, published immediately, or scheduled for a future date and time.

## Problem

Content creators may not always want to publish content immediately. They may need to prepare content in advance and publish it automatically at a selected future time.

## Solution

The demo provides a simple scheduling workflow with validation for publishing options.

Users can:

- Save content as draft
- Publish content immediately
- Schedule content for a future date and time
- Validate scheduled date and time
- Preview the saved payload

## Key Features

- Draft, publish, and schedule modes
- Future date/time validation
- Maximum scheduling window validation
- Form validation for title and content
- Mock save operation
- Status message handling
- Saved payload preview

## Tech Concepts Used

- React functional components
- React state management
- Conditional rendering
- Form validation
- Date and time handling
- Mock asynchronous API flow
- Content publishing workflow
